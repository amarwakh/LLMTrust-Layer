# Threat Category 05: LLM Supply Chain Risks

**Severity:** High
**Applicability:** All types
**OWASP LLM Top 10:** LLM05
**MITRE ATLAS:** AML.T0010

> Full content for this threat category is in progress. Core concept: LLM systems depend on multiple supply chain components — base models, fine-tuning data, inference frameworks, embedding models, vector databases, and third-party plugins. Compromise at any layer can affect the deployed system. Assessment questions: Are model versions pinned or floating to "latest"? Are third-party libraries in the LLM pipeline on a vulnerability scanning program? Is there a process for evaluating security implications of model updates before deployment?
