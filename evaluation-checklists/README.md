# Evaluation Checklists

Select the appropriate checklist for your system type and deployment stage:

| Checklist | When to Use |
|-----------|------------|
| [pre-deployment-checklist.md](pre-deployment-checklist.md) | Before any LLM system goes to production |
| [vendor-evaluation-checklist.md](vendor-evaluation-checklist.md) | When evaluating a third-party LLM provider |
| [agentic-system-checklist.md](agentic-system-checklist.md) | Additional checklist for Type C agentic systems |
| [rag-system-checklist.md](rag-system-checklist.md) | Additional checklist for Type D RAG systems |
| [ongoing-monitoring-checklist.md](ongoing-monitoring-checklist.md) | Quarterly review of deployed LLM systems |

The pre-deployment checklist applies to all system types. Use it first, then apply the additional type-specific checklist as needed.
